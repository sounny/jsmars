JSMARS is an acronym that stands for JavaScript Mission-planning and Analysis for Remote Sensing. It is a geospatial information system (GIS) developed by Sounny. JSMARS is a lightweight, browser-based GIS viewer for planetary data. It is designed to provide quick access to Mars imagery and tools without the need for heavy desktop installations.

Inspired by the powerful JMARS desktop application developed by Arizona State University.
